# RTOS 与 Embassy 共用时间源

原生线程每次睡眠 7 ms，Embassy 任务每次等待 11 ms，报告任务等待 120 ms。
共享时间接口是微秒 tick ABI，注入时钟仍是毫秒分辨率。保持原验收门槛
native>=8、embassy>=6、timer IRQ>0，并要求软件 IRQ>0，防止由下一次 timer
碰巧推进线程掩盖软件通知源缺失。计数不是吞吐量或物理精度声明。

诊断 feature `model-timeline` 仅供模型定位，在有界内存中记录事件，报告时再输出：
`N` 原生线程迭代、`E` Embassy 唤醒、`S/R` 报告开始/到期、`A` 相对毫秒闹钟、
`I` TIMER IRQ、`W` SOFT IRQ。每行包含毫秒时间和参数，最后输出 lost 计数。
时间采样在记录临界区外，锁内仅写一个事件；串口输出在普通上下文。
观察会增加执行开销，不能替代不带此 feature 的回归或真实电气计时。

默认示例保留原资源交接；本轮只在 QEMU 运行，未重新进行实板验收。历史 HIL
证据不能自动覆盖新增诊断与软件 IRQ 条件。
